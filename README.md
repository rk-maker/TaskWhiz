# ⚡ TaskWhiz

**Smart. Simple. Smarter.**  
_TaskWhiz_ is an intelligent AI-powered to-do list app that helps you organize your tasks with auto-prioritization and real-time smart suggestions. Built with modern web technologies, it's fast, responsive, and productivity-focused.

---

## ✨ Features

- ✅ **Add / Edit / Delete Tasks**
- ⚡ **AI-Powered Auto-Prioritization**
- 🤖 **Smart Suggestions While Typing**
- 🔍 **Searchable and Filterable Task List**
- 🌙 **Dark Mode Support**
- 💾 **PostgreSQL Database Integration**

---

## 🧠 How It Works

TaskWhiz uses AI to analyze your task input and automatically:

- Suggest the next word or phrase to complete your thought
- Sort tasks by estimated priority based on keywords, urgency, and context
